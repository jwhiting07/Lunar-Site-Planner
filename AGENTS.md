# Project instructions

For interface work, read `docs/ui/README.md` and inspect `docs/ui/index.html` before
changing the visual direction. They record the user-reviewed reference and preferences.

Keep the UI dark, simple, fast, and sharp-edged. Use the approved fonts. Avoid unnecessary
subheadings, rounded/pill controls, glow, purple gradients, and decorative status labels.
In particular, do not reintroduce the rejected top-right "Design study / Sample data" label.
Put necessary provenance in a quiet footer or on-demand details instead.

The saved HTML is a design reference with illustrative data, not a production science
implementation. Integrate with the team's existing code and plan when they are available.
